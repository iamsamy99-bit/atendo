# Atendo project handoff

This is a Vite landing page with a React admin dashboard, Cloudflare Pages functions, and background workers.

Use the `atendo-project` MCP server for project context and validation. Start with `project_overview` and `git_diff`. Preserve unrelated user changes in the working tree. Do not deploy to Cloudflare or send emails/messages without explicit approval.

Before finishing code changes, run `run_validation` with `typecheck`, `tests`, and `build` when relevant.
