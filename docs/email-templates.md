# Templates de correo — hola@atendo.lat

## Cómo usarlos en Gmail (plantillas nativas)

1. Gmail web → ⚙ → **Ver todos los ajustes** → pestaña **Avanzada** → **Plantillas: Habilitar** → Guardar.
2. Redacta un correo nuevo, pega el template, y en los tres puntos `⋮` del borrador → **Plantillas → Guardar borrador como plantilla → Guardar como plantilla nueva**.
3. Para usarla: correo nuevo → `⋮` → Plantillas → elige la tuya. Antes de enviar, reemplaza los `[CAMPOS]`.
4. Verifica que el remitente sea **hola@atendo.lat** (selector "De:" al redactar).
