# Atendo vs. Alternativas

## Atendo vs. Contratar una Recepcionista

| | Recepcionista humana | Agente de voz Atendo |
|---|---|---|
| Horario | 8 h/día, 5 días/semana | 24/7 incluyendo fines de semana y festivos |
| Llamadas simultáneas | 1 a la vez | Según plan |
| Costo mensual (MX) | $8,000 – $15,000 MXN + IMSS | Desde $4,900 MXN |
| Tiempo de vacaciones | Sí (obligatorio) | Nunca |
| Incapacidades | Sí | Nunca |
| Rotación de personal | Frecuente | Ninguna |
| Consistencia de información | Variable (puede olvidar o equivocarse) | Siempre igual, sin errores por descuido |
| Disponibilidad inmediata | Depende de si está libre | Siempre responde en segundos |
| Adaptación a cambios | Requiere capacitación | Cambio en el mismo día |

**Conclusión:** La recepcionista humana sigue siendo necesaria para atención presencial y situaciones complejas. El agente de voz la complementa, no la reemplaza — cubre las horas y llamadas que ella no puede manejar.

## Atendo vs. No hacer nada

Cada llamada sin respuesta es un cliente potencial perdido. Algunos datos del sector:

- El **85%** de las personas que no logran comunicarse con un negocio no vuelven a intentarlo.
- Un negocio que recibe 50 llamadas/mes y pierde el **30%** fuera de horario, pierde entre **10 y 15 oportunidades reales por mes**.
- Con el Plan Esencial a $4,900 MXN/mes, si el agente captura **1 cliente nuevo al mes** que de otra forma se perdería, el servicio ya se paga solo.
